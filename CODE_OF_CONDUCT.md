# 行為準則 / Code of Conduct

請保持尊重、就事論事、開放。騷擾、歧視、公開他人私人資訊都不被接受。
討論以工作紀律、除錯方法與工具本身為主；上游作者的貢獻應被公允對待。
本 skill 借用佛教認識論作為檢查清單，討論時不要把它變成宗教辯論或嘲諷傳統。

有疑慮請透過本 repo 的 security advisory 流程私下回報，見 [`SECURITY.md`](SECURITY.md)。

---

Be respectful, constructive, and open. Harassment, discrimination, and sharing another
person's private information are not acceptable. Keep discussion on the work disciplines
and the tooling itself, and treat the upstream author's contributions fairly. This skill
uses Buddhist epistemic principles as a checklist; do not turn that into religious
debate or mockery of the source tradition.

Report concerns privately through this repository's security advisory flow; see
[`SECURITY.md`](SECURITY.md).
